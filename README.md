# MMRecSys
This is the working repository for a Multi-Modal Recommendation System framework.

Note: Use the McAuley Labs Amazon Beauty reviews dataset to view visualizations, or replace it with some other dataset.

Access a sample (big) dataset here featuring Text embeddings and Image embeddings from the McAuley Lab's Amazon Review Dataset on 3 categories of products taken together: https://huggingface.co/datasets/WhiteRavenPlus/McAuleyLabsAmazonReviewTextEmbeddings_BERT
